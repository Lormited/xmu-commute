# 拾课 · Expo 交互原型

2026-10-29。Android / iOS 优先，延续相邻 expo-style-sample 的 v1 视觉；v1 未修改。全部数据与操作均为模拟，状态仅保存在本次运行内存。

## 运行

```powershell
pnpm install --frozen-lockfile
pnpm phone
```

手机端口 8899；SDK 58 对应的 Expo Go 或包含当前原生依赖的 development build。自定义 development build 新增原生依赖后需重新构建。现有 react-native-svg 15.16.0 用连续路径绘制圆环与勾线；本次未添加依赖。

```powershell
pnpm web
pnpm check
pnpm export:all
```

浏览器预览 http://localhost:8897/，内容最大宽 440；复用已有 Metro。export:all 导出 Web、Android / iOS Hermes 资源，不生成 APK / IPA，也不代表真机验收。

## 调试设置

入口：**我的 → 调试设置**。所有选项均以底部浮窗选择。

- 课程样式已移至普通设置，只保留双列卡片 / 留白列表；移除横课签、旧分组轻列表与首页信息排序调试项。课程列表、详情、冲突浮窗均无课程图标。
- 账号卡片：原版学号在上 / 新版学号在下，选择后点“查看效果”回我的页面；两版均为 14 位学号、无校名，原版右侧图标缩至 28 点并预留 12 点间隔。
- 首页固定宽松间距 43，课表留白固定左 0 / 右 8；删除对应比较入口、状态与事件。时间栏宽 36。
- 课表顶部间距固定 6，不再提供调试项。
- 今日卡片已固定为图标与三行；删除其余排版、状态、事件和调试入口。
- 今日日期固定底部短线，删除浅底、边框和样式切换。仍以 2026-10-26 为演示日，只在完整日期匹配时标识，其他周不标识。
- 冲突样式已移至普通设置，按交错 / 重叠排序；删除描边状态、开关与其余样式。
- 场景：正常 / 空集合 / 正在加载 / 无网络 / 未登录 / 长内容与锁定。
- 签到方式：数字码 / 二维码 / 雷达；回执：成功 / 已结束 / 失败。体验按钮重复新建，未登录 / 空集合 / 加载 / 无网络时禁用。

账号卡片选项可直接“查看效果”，课程与作业样式在浮窗内实时预览。切换无网络保留已有内存数据；其余场景重置模拟记录。首次读取失败按空集合展示；已有数据时离线继续显示，不单独展示缓存提示。登录过期、网络失败、部分历史失败场景已删除；原型不模拟真实自动续登。

四个主页面与普通子页面共用顶部安全区、48 点标题栏，移除主页面额外的 12 点顶部留白。全部内容文字与输入文字使用中性黑灰，保留原渐变、淡色材质与功能图标。

首页两区标题栏到内容统一 14 点；留白作业列表的首行去掉重复的顶部内边距，其余行、浅底 / 整组样式及学习页列表不变。课程区到作业区固定使用 43 点宽松间隔，正常、空集合与加载场景一致。

## 动画与边界

底栏即时切换；详情为原生 Stack 180ms 淡入淡出；签到和选项为原生 formSheet。纵横滚动使用平台列表与分页，保留回弹；移动超过 8 点取消点击。浏览器只近似手机布局。

周数、学习标签、历史标签在滑动约 40% 时更新，以手势起点计算，避免提早更新后反复跳动。点选标签使用同一个分页列表的滚动动画；中途触摸可接管，减少动态效果时即时切换。程序滚动途中不回报经过的旧标签。空集合首页课程卡片与作业标题同样保持 43 点间距。

签到为一个连续圆弧和一条连续勾线，圆端点 / 圆连接；保留 80 容器、68 外圈、43 勾形。成功时 420ms 内旋转闭合，270ms 起画勾，390ms 起向右上绘制，600ms 完成。顶栏复用相同连续勾线。减少动态效果时直接显示静态状态。

没有真实学校请求、登录 / 自动续登、签到提交、设备权限、持久缓存、后台提醒、服务端或活动公告。验证与未测项见 VALIDATION.md；设计依据见 DESIGN.md。旧截图不能作为当前视觉证据。
